# About Library

This page is made for book geeks, to save which books they already read or they want to read. You SAve title,author,pages, and if you already read it or not.

## For Developers

This project is part of [The Odin Project](https://www.theodinproject.com/) curriculum, where I’ve learned a lot about making websites with JavaScript.  
HTML provides the main structure, CSS handles the styling, and JavaScript powers the functionality.  
The main purpose of this project is to practice JavaScript.  

All the books are saved in array, which is preety simple, And each book has it own id made with crypto.randomUUID(), so its easier to manipulate with each one.
