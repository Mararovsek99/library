# About Library

This page is made for book lovers — a simple app to keep track of the books you’ve read or want to read.  
You can save the **title**, **author**, **number of pages**, and mark whether you’ve already read the book or not.


## For Developers

This project is part of [The Odin Project](https://www.theodinproject.com/) curriculum, where I’ve learned a lot about building websites with JavaScript.  
HTML provides the main structure, CSS handles the styling, and JavaScript powers the functionality.  
The main purpose of this project is to practice JavaScript.  

All books are stored in an array, which keeps the implementation simple.  
Each book has its own unique **ID**, generated with `crypto.randomUUID()`, making it easier to manipulate individual entries.
